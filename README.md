# webgpu-lbm

Моделирование течения в каверне с движущейся крышкой (lid-driven cavity) методом решёточных уравнений Больцмана (LBM, D2Q9, BGK) на WebGPU. Расчёт целиком идёт в compute-шейдерах, а результат выводится в браузере как тепловая карта модуля скорости.

**Демо:** https://semen1996.github.io/webgpu-lbm/

Нужен браузер с поддержкой WebGPU: свежий Chrome, Edge или Safari, либо Firefox с включённым WebGPU.

## Параметры

Задаются в [src/config.ts](src/config.ts):

| Параметр | По умолчанию | Описание |
| --- | --- | --- |
| `nx`, `ny` | 301 × 301 | размер сетки |
| `u0` | 0.1 | скорость крышки в решёточных единицах |
| `Re` | 1000 | число Рейнольдса |

Параметр релаксации считается по формуле `ω = 1 / (3ν + 0.5)`, где `ν = u0·(ny − 1) / Re`.

## Запуск

```bash
npm install
npm run dev       # dev-сервер Vite
npm run build     # проверка типов (tsc) и сборка в dist/
npm run preview   # просмотр собранной версии
```

Dev-сервер открывается по адресу `http://localhost:5173/webgpu-lbm/`.

## Как устроен шаг

Один шаг LBM состоит из двух compute-проходов по двум ping-pong буферам `f`:

1. **collide-stream** выполняет столкновение BGK и перенос (pull-схема).
2. **boundary-macroscopic** применяет граничные условия и пересчитывает `ρ`, `u`, `v`. На неподвижных стенках используется bounce-back, на крышке условие Zou/He.

Отрисовка сделана через полноэкранный треугольник: фрагментный шейдер читает буфер макрополей и раскрашивает `|u|/u0`.

## Структура

```
src/
  config.ts      параметры сетки, физики и отображения
  main.ts        создание ресурсов GPU и цикл симуляции
  lbm/           буферы, пайплайны и шейдеры расчёта
  render/        тепловая карта
  common/        общий буфер макрополей и common.wgsl
  init-gpu/      инициализация WebGPU и canvas
  ui/            подписи осей и времени
```
